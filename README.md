# Домашнее задание к работе 6

## Условие задачи

Пользователь вводит целое число **N**. Найти сумму цифр этого числа и проверить, делится ли полученная сумма на **3** без остатка.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Ввести исходные данные:
    - `n` — целое число, введенное пользователем.
3. Инициализировать переменные:
    - `sum = 0` — переменная для накопления суммы цифр.
    - `x = abs(n)` — рабочая переменная, содержащая модуль числа (для корректной работы с отрицательными числами).
4. Проверить корректность ввода:
    - Если введено не число, вывести сообщение об ошибке и завершить программу.
5. Начать цикл вычисления суммы цифр (`while x > 0`):
    - Найти остаток от деления `x` на 10 (последняя цифра числа).
    - Прибавить полученную цифру к `sum`.
    - Разделить `x` на 10 нацело (удалить последнюю цифру числа).
6. Проверить кратность суммы трем:
    - Если `sum % 3 == 0`, то сумма цифр кратна трем.
    - Иначе — сумма цифр не кратна трем.
7. Вывести результаты расчетов в консоль.
8. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");
    int n, sum = 0, x;

    printf("Введите число N: ");
    if (scanf("%d", &n) != 1) {
        printf("ошибка \n");
        return 1;
    }
    x = abs(n); 
    while (x > 0)
    {
        sum += x % 10;
        x /= 10;
    }
    if (sum % 3 == 0) {
        printf("сумма цифр числа (%d) кратна трем\n", sum);
    }
    else {
        printf("сумма цифр числа (%d) не кратна трем\n", sum);
    }

    return 0;
}
```
